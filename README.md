## Overview
This repository contains the code and outputs for **Part E (Option E4: Explainable Decision Tree)**. An entropy-based Decision Tree classifier is trained on SaaS free-trial user data to identify key behavioral drivers of paid conversion and generate clear product rules.

## Files Included
- `dvpd project/code.py` — Data generation, preprocessing, Decision Tree model training, evaluation metrics, and visualization script.
- `README.md` — Project overview and usage instructions.

## How to Run
Run `code.py` in Python, Jupyter Notebook, or Google Colab with `seed = 70` to reproduce the results and figures.
